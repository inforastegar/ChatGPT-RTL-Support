# آزمون ساختار DOM زنده (بدون متن خصوصی)

1. در ChatGPT و حالت On، DevTools را با F12 باز کن.
2. از Elements، ابزار Select Element را انتخاب کن و روی یکی از **پاراگراف‌های فارسی داخل گفتگو** کلیک کن.
3. به Console برو و محتوای فایل diagnostics/live_dom_probe.js را کپی و اجرا کن.
4. خروجی JSON را ارسال کن. قبل از ارسال آن را بررسی کن.

این ابزار فقط اطلاعات ساختاری DOM، وضعیت CSS و شمارنده‌ها را گزارش می‌کند؛ متن پیام‌ها، لینک‌ها، HTML و URL را جمع‌آوری نمی‌کند و چیزی ارسال نمی‌کند.

تفسیر:
- اگر messages و turns هر دو صفرند، انتخابگرهای قدیمی احتمالاً جواب نمی‌دهند.
- اگر mainMarked صفر و allMarked غیرصفر است، صفحه بیرون از main علامت‌گذاری شده است.
- اگر target.inMessage برابر false است، عنصر انتخاب‌شده تحت محدوده پیام فعلی نیست.
- اگر rtlMark برابر rtl است اما computedAlign برابر left است، مشکل از تداخل CSS یا قواعد خاص عنصر است.
- اگر extensionEnabled یا stylePresent نادرست است، ابتدا اجرای اکستنشن بررسی شود.

این فقط ابزار تشخیصی است، نه یک نسخه جدید اصلاح RTL.
